# 결과 보고 틀

```md
## 결론
<가장 큰 병목 한 줄과 그 비중> → <무엇을 바꿔서> → <얼마나 좋아졌는지>

## 측정
| 항목 | 전 | 후 | 변화 | 잰 방법 |
|---|---|---|---|---|
| 주문 목록 API p95 | 1.8초 | 240ms | −87% | k6, 50명 동시, 1만 건, 7회 중간값 |

조건: <기기·데이터 크기·빌드 종류>, 편차: <±%>

## 바꾼 것
1. <파일:줄> — <무엇을 왜> (효과: …)
2. …

## 정확도 확인
- <테스트 명령과 결과: 예) 152개 통과, 0개 실패> / <전후 결과 비교 방법>

## 남은 것
- 다음 병목 후보: <무엇, 예상 효과, 위험>
- 측정하지 못한 것: <무엇, 어떻게 재면 되는지>
```

쓰지 말 것: "빨라졌을 것입니다", "개선될 것으로 보입니다" 같은 측정 없는 주장. 재지 못했으면 "측정 안 함"이라고 쓰세요.
