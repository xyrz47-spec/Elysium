# 숫자와 차트

## 1. 형태부터 고르기(색은 마지막)
| 데이터의 일 | 형태 |
|---|---|
| 핵심 숫자 하나 | 차트 말고 큰 숫자 + 짧은 설명(+ 전 기간 대비) |
| 항목끼리 크기 비교 | 막대(가로 막대는 이름이 길 때) |
| 시간에 따른 변화 | 선(점이 적으면 막대) |
| 전체 중 비율(항목 2~5개) | 쌓은 막대 하나 또는 도넛. 원 조각 6개 이상은 피하기 |
| 분포 | 히스토그램, 상자 그림 |
| 두 값의 관계 | 산점도 |
| 많은 칸의 크기 | 히트맵(한 가지 색의 진하기) |
| 정확한 값이 중요 | 표 |
그래프로 보여 줄 필요가 없으면 숫자나 표가 정답입니다.

## 2. 색의 역할
- **구분(범주)**: 정해진 순서대로, 반복해 돌리지 않기. 8개를 넘으면 "기타"로 묶거나 작은 차트 여러 개로.
- **크기(순차)**: 한 색의 옅음 → 진함.
- **양쪽(발산)**: 두 색 + 가운데 회색(가운데에 색을 쓰지 않기).
- **상태**: 좋음·경고·심각·위험은 따로 정해 두고, 범주 색으로 재사용하지 않기. 항상 아이콘·글과 함께.
- **색은 항목을 따라감**: 필터로 항목 수가 바뀌어도 남은 항목의 색이 바뀌지 않게.
- 색각 이상(적록)에서도 구분되는지 확인하고, 구분이 약하면 무늬·모양·직접 라벨을 함께.

## 3. 그리는 규칙
- 축은 하나. 단위가 다른 두 값을 한 차트에 이중 축으로 겹치지 말고 차트를 나누기.
- 막대는 0에서 시작, 끝만 살짝 둥글게(4px), 막대 사이 2px 간격. 선은 2px, 점은 8px 이상.
- 격자·축은 흐리게, 데이터가 주인공. 숫자 라벨은 필요한 곳에만(모든 점에 숫자 붙이지 않기).
- 범례는 계열이 2개 이상일 때. 4개 이하면 선 끝에 직접 이름을 붙이기.
- 값·라벨 글자는 계열 색이 아니라 글자 색으로(옆에 색 표시를 두어 구분).
- 다크 모드 색은 같은 색 단계에서 따로 골라 다크 바탕에서 대비 확인.

## 4. 상호작용
- 막대·점마다 올리면(포커스하면) 값이 보이는 툴팁, 선 그래프는 세로 기준선 + 툴팁. 누르는 영역은 표시보다 크게.
- 기간·필터는 차트 위 한 줄에, 바꾸면 차트를 **다시 그리기**(쌓아 올리지 않기). 같은 데이터로 다시 그릴 때는 이전 요소를 지우고 새로.
- 표 보기(같은 데이터를 표로)를 제공하면 화면 읽기와 정확한 값 확인에 좋습니다.

## 5. 핵심 숫자 칸(stat tile)
- 큰 숫자(고정폭 숫자) + 작은 설명 + 변화(▲3.2% 처럼 기호와 색과 글을 함께).
- 단위·기간을 분명히("오늘", "지난 7일"), 추정치면 "추정"이라고.
- 칸이 여러 개면 같은 높이·정렬, 중요한 것 하나만 크게.
