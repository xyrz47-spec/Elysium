# 컴포넌트 조립과 라이브러리

## 공통 원칙
1. **있는 것 먼저**: 프로젝트의 컴포넌트, 그다음 쓰고 있는 라이브러리, 그다음 새로 만들기.
2. **조합으로 해결**: 설정 화면 = 탭 + 카드 + 폼 컨트롤, 대시보드 = 사이드바 + 카드 + 차트 + 표.
3. **기본 변형 먼저**: `variant`·`size` 같은 기본 선택지로 안 될 때만 스타일 추가.
4. **의미 있는 색 토큰만**: `bg-primary`, `text-muted-foreground`처럼 역할 이름. `bg-blue-500` 같은 날값 금지. 다크 모드를 위해 `dark:`로 색을 따로 덮지 말고 토큰이 바뀌게.
5. **결정은 한 번**: 버튼 높이·여백·반지름, 입력칸 높이, 카드 여백, 표 행 높이를 정하면 모든 곳에 같게.
6. 같은 모양을 세 번 쓰면 컴포넌트로 뽑기. 반대로 한 번 쓰는 것은 굳이 일반화하지 않기.

## 레이아웃 습관
- 간격은 `gap`으로(플렉스·그리드). 형제 사이 여백을 `margin`으로 하나씩 주지 않기(Tailwind의 `space-x/y`보다 `flex gap`).
- 정사각형은 `size-*`(또는 `aspect-ratio`), 말줄임은 한 줄 유틸리티(`truncate`).
- 겹치는 요소(모달·팝오버·메뉴)는 라이브러리가 쌓임 순서를 관리하게. `z-index`를 임의로 올리지 않기. 앱 전체에 단계(기본·떠 있는 패널·팝오버·모달·알림)를 정해 두기.
- 조건부 클래스는 도우미(`cn()`, `clsx`)로, 문자열 이어 붙이기 대신.

## shadcn/ui를 쓰는 프로젝트
- 컴포넌트는 CLI로 소스를 추가(`npx shadcn@latest add …`), 먼저 `info`로 설정·설치된 것 확인, 필요하면 `search`로 레지스트리 확인.
- 폼은 필드 그룹·필드 구성 요소로, 검증 상태는 `aria-invalid`(컨트롤)와 상태 속성(필드)로.
- 선택지 2~7개는 토글 그룹, 관련 체크박스·라디오는 fieldset + legend.
- 목록형 항목은 반드시 그 그룹 안에(SelectItem → SelectGroup 등).
- Dialog·Sheet·Drawer에는 제목이 꼭 있어야 함(보이지 않게 하려면 화면에서만 숨김).
- 카드는 머리·제목·설명·내용·꼬리를 나눠 쓰기. 안내 상자는 Alert, 빈 상태는 Empty, 뼈대는 Skeleton, 구분선은 Separator, 꼬리표는 Badge.
- 버튼에 로딩 속성을 만들지 말고 스피너 + 비활성화로 조합.

## Tailwind + daisyUI
- daisyUI는 컴포넌트 클래스(btn, card, modal…)와 의미 색(primary, base-100…)·테마를 줍니다. 쓰기 전에 그 컴포넌트의 문서를 읽고 정해진 클래스 조합을 따르세요.
- 테마 색을 쓰면 다크·라이트가 함께 바뀝니다. 색을 날값으로 쓰지 마세요.

## 움직이는 컴포넌트(Magic UI 등)
- 결과부터 정하기: 섹션 종류, 분위기, 움직임 세기, 반응형 동작.
- 사회적 증거·로고 줄 → 흐르는 띠(marquee), 히어로 → 지구본·격자·빛 배경 하나, 강조 버튼 → 반짝이는 버튼 하나.
- 생성된 경로에서 가져오고, 컴포넌트 API는 그대로 두고 속성으로 조정. 필요한 의존성·키프레임 함께 추가.

## 대화형(채팅·AI) 화면 패턴
- 메시지 목록은 스크롤 영역 하나가 관리: 새 글이 오면 바닥을 따라가되, 사용자가 위로 올리면 멈추고 "최신으로" 버튼.
- 스트리밍 중인 답은 한 덩어리로 자라게(글자마다 레이아웃이 크게 흔들리지 않게), 끝나면 복사·다시 하기.
- AI의 과정(생각·도구 사용·출처)은 접을 수 있는 줄로, 본문과 시각적으로 구분.
- 입력창: 여러 줄 자동 높이, Enter 보내기·Shift+Enter 줄바꿈(한글 조합 중 무시), 보내는 중에는 중지 버튼.
- 첨부·시스템 안내·날짜 구분은 메시지와 다른 모양으로.

## 표와 목록
- 숫자 열은 오른쪽 정렬 + 고정폭 숫자, 글 열은 왼쪽. 머리글은 고정(sticky).
- 행 높이 하나로, 마우스를 올리면 옅게 강조, 선택은 체크박스 + 분명한 배경.
- 1,000행이 넘으면 가상화 또는 페이지 나누기. 정렬·필터 상태는 주소에.
- 좁은 화면에서는 가로 스크롤 상자 안에 넣거나, 카드 목록으로 바꾸기.
