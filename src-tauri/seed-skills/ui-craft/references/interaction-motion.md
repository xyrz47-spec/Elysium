# 상호작용과 모션

## 상호작용 규칙
- **눌렀다는 것을 바로 보여 주기**: 누르는 순간(100ms 안) 상태가 바뀌어야 합니다. 오래 걸리면 버튼 글은 그대로 두고 옆에 진행 표시, 중복 제출은 막기.
- **낙관적 갱신**: 성공할 가능성이 높은 동작은 먼저 화면을 바꾸고, 실패하면 되돌리고 알리기(또는 되돌리기 버튼).
- **되돌릴 수 없는 동작**: 확인 창에 무엇이 사라지는지 구체적으로 적고, 위험한 버튼은 빨간색, 기본 초점은 "취소". 또는 몇 초간 되돌리기 알림.
- **상태는 주소에**: 탭·필터·검색어·페이지처럼 다시 열었을 때 그대로여야 하는 것은 URL(또는 저장소)에. 새로 고침·뒤로 가기가 동작해야 합니다.
- **탐색은 진짜 링크**(`<a href>`): 새 탭 열기·주소 복사가 되도록.
- **포커스 관리**: 모달·서랍을 열면 초점을 안으로, Esc로 닫기, 닫으면 원래 버튼으로.
- **입력**: Enter로 제출, 여러 줄 입력은 Ctrl/Cmd+Enter. 붙여넣기 막지 않기. 앞뒤 공백 자르기.
- **터치**: 누르는 영역 44px, 끌기에는 누르기 대안, 넘치는 스크롤은 `overscroll-behavior`로 제어, 길게 누르기 의존 금지.
- **마우스 올림(hover)만으로 정보 숨기지 않기**: 터치에는 hover가 없습니다. 툴팁보다 옆에 보이는 도움말을 우선.
- **단축키**: 자주 쓰는 동작만, 화면 어딘가에 표시(툴팁·메뉴 옆).

## 모션 원칙
- **이유가 있는 움직임만**: (1) 무엇이 바뀌었는지 보여 주기(열림·닫힘·선택 이동·추가·삭제) (2) 원인과 결과 잇기(누른 곳에서 퍼지기) (3) 의도한 즐거움 한 군데.
- 저절로 반복되는 장식 모션은 화면에 하나만. 섹션마다 같은 등장 효과를 붙이면 생성된 화면처럼 보입니다. 한 번의 잘 짜인 등장(페이지 로드 연출)이 흩어진 효과보다 낫습니다.
- **성능**: `transform`과 `opacity`만 움직이기. `width·height·top·left·margin`을 움직이면 레이아웃이 다시 계산됩니다. `transition: all` 금지(바꿀 속성만 적기).
- **끊김 없이**: 움직이는 중에 다시 눌러도 그 자리에서 이어지게(CSS transition은 자연스럽게 이어짐, 키프레임은 끊김).
- **물리적 출발점**: 메뉴는 버튼에서, 알림은 나타나는 가장자리에서. `transform-origin`을 맞추기.
- **줄이기 설정**: `@media (prefers-reduced-motion: reduce)`에서 이동·확대를 없애고 짧은 투명도 변화만.

## 시간과 곡선(출발점)
| 종류 | 시간 | 곡선 |
|---|---|---|
| 눌림·상태 변화 | 100~150ms | ease-out |
| 작은 요소 등장(툴팁·메뉴) | 150~200ms | ease-out |
| 패널·서랍·모달 | 250~350ms | 빠르게 시작해 천천히 멈춤(예: cubic-bezier(.2,.8,.2,1)) |
| 선택 표시 이동(미끄러지는 라디오·탭) | 250~450ms | 살짝 튀는 스프링(cubic-bezier(.34,1.56,.64,1)) |
| 사라짐 | 등장보다 짧게(약 70%) | ease-in |
큰 화면 이동일수록 조금 길게, 자주 쓰는 동작일수록 짧게.

## 미끄러지는 선택 표시(세그먼트·탭) 만드는 법
1. 선택된 칸의 `offsetLeft`·`offsetWidth`를 재서, 뒤에 깔린 판(thumb)의 `transform: translateX()`와 `width`에 넣기.
2. 처음 그릴 때는 움직임 없이 제자리에 두고, 그다음부터만 transition을 켜기(처음에 왼쪽에서 날아오지 않게).
3. 글꼴이 늦게 불러와 폭이 바뀌면 다시 재기(ResizeObserver).
4. 역할은 `radiogroup`/`radio`(또는 `tablist`/`tab`), 화살표 키로 이동.

## 움직이는 라이브러리를 쓸 때(Magic UI 등)
- 핵심 효과 하나 + 받쳐 주는 효과 하나로 시작하고, 필요할 때만 늘리기. 한 화면에 큰 움직임을 여러 개 겹치지 않기.
- 컴포넌트 내부를 고쳐 쓰기보다 속성·클래스로 조정. 필요한 키프레임·CSS를 같이 넣기.
- 배경 효과(입자·격자·빛)는 내용 뒤에, 대비를 해치지 않게, 줄이기 설정에서 멈추기.
