# 주장 나누기

## 좋은 주장 단위
- 하나의 문장이 하나의 사실만 말하게 쪼개세요.
  - 원문: "A사는 2019년 서울에서 창업해 3년 만에 직원 500명이 됐다."
  - 주장: ① A사 창업 연도 2019 ② 창업 장소 서울 ③ 2022년 무렵 직원 수 약 500명
- 숨은 전제도 꺼내세요: "가장 큰", "처음으로", "~때문에"는 비교 대상·순서·인과를 따로 확인해야 합니다.

## 주장의 종류와 확인 방법
| 종류 | 예 | 확인 |
|---|---|---|
| 숫자·통계 | 인구, 비율, 금액 | 원 통계(기관·연도·정의), 다시 계산 |
| 날짜·순서 | 출시일, 최초 | 공식 발표·기록, "최초"는 반례 찾기 |
| 인물·직책 | 누가 무엇을 맡음 | 공식 소개·최신 발표(기준 시점) |
| 인용 | "누가 이렇게 말했다" | 원 발언(영상·원문), 앞뒤 맥락 |
| 인과 | X 때문에 Y | 상관과 인과 구분, 연구 설계·다른 설명 |
| 기술 사실 | API가 이렇게 동작 | 공식 문서·소스 코드·직접 실행 |
| 법·제도 | 세율, 규정 | 법령 원문·시행일·개정 여부 |
| 과학·의학 | 효과, 위험 | 체계적 문헌 고찰·가이드라인 > 단일 연구 > 기사 |

## 주장마다 적을 것
- 확인할 1차 출처: (예: 통계청 2024 인구총조사, 공식 API 문서 v3)
- 확인 방법: 찾기 / 계산 / 실행 / 원문 대조
- 반증 조건: 무엇이 나오면 틀린 것인지(예: 2019년이 아닌 다른 연도의 법인 등기)

## 사실이 아닌 것
- 의견("좋다", "최고다"), 예측("내년에 오를 것"), 가치 판단은 맞고 틀림을 판정하지 말고 "의견"으로 표시하세요. 그 근거로 든 사실만 확인합니다.
