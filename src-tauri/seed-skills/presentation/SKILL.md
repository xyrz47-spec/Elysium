# 발표 기획

이 스킬은 발표의 목적과 청중을 정의하고, 설득력 있는 스토리라인(상황-문제-해결)과 슬라이드별 구성안·시각자료·발표 노트를 설계합니다.
목표는 **슬라이드 위 글자는 최소한으로 줄이고, 한 장에 하나의 핵심 메시지만 선명하게 전달하는 발표 설계안**을 만드는 것입니다.

## 1. 먼저 확인할 것
- 사용자가 준 자료나 요청에서 다음 네 가지를 먼저 파악하세요:
  - **발표 주제와 핵심 내용**: 무엇을 전달하거나 제안하는가.
  - **청중**: 누구에게 발표하며, 그들이 이미 아는 것과 가장 궁금해할 점은 무엇인가.
  - **목표(행동 유도)**: 발표가 끝났을 때 청중이 어떤 결정이나 행동을 해야 하는가.
  - **발표 시간과 장수**: 전체 몇 분 발표인지, 질의응답(Q&A)이 포함되는지, 희망 슬라이드 수가 있는지.
- 위 정보가 일부 빠져 있어도 문맥으로 합리적인 추정이 가능하면 가정한 기준을 첫머리에 밝히고 바로 구성안을 작성하세요(예: "일반 임원 보고 기준 10분·8장 내외로 구성합니다").
- 주제나 핵심 내용이 아예 없어 기획 자체가 불가능할 때만 꼭 필요한 질문을 1~2개 이내로 짧게 물으세요.

## 2. 발표 설계 절차
- **1단계 — 청중 및 목표 정의**: 청중의 관심사·우려 사항을 짚고, 발표 후 얻어낼 구체적인 결론 한 문장을 정합니다.
- **2단계 — 스토리라인(SCR) 구축**: 전체 흐름을 상황(Situation) → 문제·전환점(Complication) → 해결·제안(Resolution) 구조로 잡습니다.
  - **상황(S)**: 청중이 공감하는 현재 배경과 사실.
  - **문제(C)**: 왜 지금 변화나 결정이 필요한지 보여주는 한계·위기·기회.
  - **해결(R)**: 우리가 제안하는 핵심 해법, 실행 계획, 기대 효과.
- **3단계 — 슬라이드별 1메시지 배분**: 전체 흐름을 슬라이드 단위로 쪼개고, 각 장의 제목 자체가 결론을 담은 **완결된 한 줄 메시지(헤드라인)**가 되도록 작성합니다(예: "매출 현황" 대신 "3분기 매출은 신제품 효과로 전분기 대비 상승").
- **4단계 — 화면 문구 최소화**: 슬라이드 본문에 들어갈 글자는 개조식 키워드나 짧은 구절로 최대 3~4줄(줄당 7단어 내외)까지만 남기고, 설명 문장은 모두 발표 노트로 뺍니다.
- **5단계 — 시각자료 및 차트 제안**: 글자 대신 메시지를 직관적으로 보여줄 시각 요소(막대·꺾은선·폭포 차트, 2x2 매트릭스, 프로세스 화살표, 전후 비교표, 핵심 숫자 강조 등)를 구체적으로 지정합니다.
- **6단계 — 발표 노트 및 시간 배분**: 발표자가 실제로 말할 구어체 대본(핵심 포인트와 다음 장으로 넘어가는 연결 멘트 포함)을 쓰고, 슬라이드별 소요 시간을 분·초 단위로 현실성 있게 배분합니다(보통 1장당 1~2분 기준).

## 3. 품질 원칙과 금지 사항
- **한 슬라이드 한 메시지 원칙**: 한 장에 두 가지 이상의 주제를 섞지 마세요. 내용이 많으면 슬라이드를 나누세요.
- **슬라이드 대본화 금지**: 슬라이드 화면 항목에 긴 서술형 문장이나 문단을 넣지 마세요. 읽는 슬라이드가 아니라 보는 슬라이드로 설계해야 합니다.
- **수치·근거 날조 금지**: 사용자가 제공하지 않은 통계, 매출 수치, 시장 규모, 출처, 사례를 임의로 지어내지 마세요.
- **빈자리 표시**: 설득을 위해 수치나 근거 자료가 꼭 필요한 자리라면 가짜 숫자를 넣지 말고 `[실제 전환율 수치 입력 필요]` 또는 `[출처 확인 필요]`처럼 표시해 사용자가 채우도록 안내하세요.
- **불확실성 명시**: 추정치나 가정을 사용했을 때는 발표 노트나 참고란에 추정 기준과 불확실한 점을 분명히 밝히세요.

## 4. 출력 형식
아래 구조에 맞춰 발표 기획안을 출력하세요. 사용자가 특정 구간만 요청한 경우가 아니라면 전체 구성을 빠짐없이 제시합니다.

### [발표 개요]
- **발표 제목**: (주제를 명확히 드러내는 제목)
- **대상 청중 / 발표 목표**: (청중의 특성 / 발표 후 이끌어낼 결정이나 행동)
- **기준 시간 / 총 슬라이드 수**: (예: 발표 10분 + Q&A 5분 / 총 8장, 가정한 경우 기준 명시)

### [전체 스토리라인 (SCR)]
- **상황(Situation)**: (1~2문장 요약 — 슬라이드 #~#번)
- **문제(Complication)**: (1~2문장 요약 — 슬라이드 #~#번)
- **해결(Resolution)**: (1~2문장 요약 — 슬라이드 #~#번)

### [슬라이드별 상세 구성]
각 슬라이드를 아래 항목으로 반복해 작성하세요:
- **슬라이드 # [구간: 도입/본론/결론] (배정 시간: X분 X초)**
  - **핵심 메시지(헤드라인)**: 슬라이드 상단에 들어갈 결론형 한 문장
  - **화면 텍스트(최소화)**: 슬라이드에 표시할 핵심 키워드·수치 3개 이내
  - **권장 시각자료**: 차트 종류, 도식 구조, 강조할 데이터 위치 설명
  - **발표 노트(대본)**: 실제 발표 시 말할 핵심 설명과 다음 슬라이드 연결 멘트

### [예상 질문 및 보충 준비 사항]
- **청중 예상 질문 2~3개와 핵심 답변 요지**
- **추가 확보가 필요한 데이터·근거 목록**: (`[입력 필요]`로 표시한 항목 정리)
